# 📚 BookSaw – Online Bookstore

## 📖 About the Project

BookSaw is a responsive online bookstore website designed to provide users with a simple and attractive platform to explore books, discover popular titles, and browse featured collections.

The project focuses on creating a user-friendly bookstore interface with book categories, product displays, special offers, and a clean, modern design. It is developed using HTML, CSS, Bootstrap, and JavaScript.

## 🎯 Project Objective

The main objective of this project is to design an attractive and responsive online bookstore website that allows users to:

* Browse and explore different books.
* View featured and popular books.
* Discover books by category.
* View book details such as title, author, and price.
* Add books to the cart interface.
* Explore special book offers.
* Read book-related articles.
* Subscribe to a newsletter.

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project

Open the project folder in Visual Studio Code.

### Step 3: Run the Website

If running the provided HTML template directly:

1. Open the `index.html` file.
2. Use Live Server in VS Code.
3. View the website in your browser.

If the Django backend is configured, run:

```bash
python manage.py runserver
```

Then open the local server URL displayed in the terminal.
